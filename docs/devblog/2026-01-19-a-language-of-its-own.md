> **Reconstructed from the commit log.** 24 of 47 commits carry a message.

The last day of the January push, and the one that set up everything after it.

**`Add DramScript editor core`.** The engine stopped being driven by clicking and
started being driven by *writing*. Everything the project became — 43 commands,
1,240 scenes, games generated by script rather than assembled by hand — descends
from this commit.

**`Add Episode system`**, with load support and scene management. Worth flagging
because it causes a small collision seven months later: Doug starts calling a
single unit of play an "episode", but "Episode" is already a type that *groups*
scenes into a release. In August we nearly did a global rename that would have
merged two different concepts. The vocabulary got fixed instead of the code — a
unit of play is a **scene**.

**`Add cloud publish flow`** and `Enable auth and patch UI` — the first attempt at
getting a game to somebody else. Also `Enable picker directory save`, which is the
unglamorous other half of the same problem.

**`Remove ElevenLabs API key UI`.** A key was being entered in the browser; it
stopped being. The right instinct, and the same one that in August puts the
ElevenLabs and Flux bridges server-side, where a key can never reach a player.

**Then it stopped.** The next commit in this repository is dated **August 17** —
seven months later.

Nothing in the log says why. The August work opens with removals and repairs
(`Repair Index.tsx encoding`, `Remove the rest-period pacing system`), which is
what returning to your own project looks like: you clean before you build.
